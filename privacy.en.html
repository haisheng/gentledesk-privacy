GENTLEDESK

Privacy policy and data practices

Extension version 1.6.3 · Effective October 28, 2026

GentleDesk (project name: DeskAssit) replaces the Chrome new tab page with a personal desktop for shortcuts, tasks, calendars and information cards. This policy covers the extension, its web version and the optional macOS / Windows companion.

GentleDesk has no advertising or analytics SDKs and does not sell user data. Desktop configuration is stored locally by default. Optional services communicate with destinations you choose and authorize. Chrome account sync is off until you explicitly enable it.

2. Optional connections and recipients

API and AI cards: requests go to HTTPS endpoints you enter and authorize, not a GentleDesk relay server. AI requests contain the prompt you wrote; your local files, calendar and other cards are not automatically attached. Provider fees and the provider's own privacy terms may apply. Requests omit cookies and reject redirects. Removing a card clears its token and results; domain permission is removed when no remaining connected card or calendar needs it.

Web search and links: submitting a web search sends that query to your selected Bing, Google or Baidu provider. Opening a shortcut or footer link contacts that destination. The preinstalled Tools shortcut and footer link do not make automatic visits or add click tracking.

Apple Calendar and Reminders: require the separate macOS companion and system permission you approve. System access is database-wide; GentleDesk caches and manages only calendars and reminder lists you select. Source / account labels, event details and reminder names, dates, notes and completion state stay locally. Confirmed edits or deletions are written to the selected system source. Apple / iCloud handles its own account sync and notifications. Disconnecting removes selection records and extension caches without deleting original events or reminders. Revoke system access separately in macOS Privacy & Security.

Windows local calendars: the companion reads only classic Outlook calendars or local ICS files you explicitly select. Local ICS files must be read to parse events. The connection is read-only; no Outlook email, contacts or passwords are read. Selected paths stay in the companion's user-specific configuration, while the extension receives opaque references and calendar data. New Outlook is not supported through this COM connection. Disconnecting removes selections and caches, not original calendars or files.

Native installers: personalized ZIP packages are generated locally with the current extension ID. That ID is not uploaded for personalization. Installation registers the exact ID for the current user. Homebrew / GitHub downloads may produce normal download logs; the extension ID is passed only to a local setup command. The extension does not automatically install Homebrew, run a terminal or bypass system installation approval.

Macro updates: after explicit opt-in and exact-origin permission, requests retrieve public data from the New York Fed, US Treasury, TreasuryDirect, Investing.com and IMF. No account information, cookies or other card data is attached. While the page is visible, updates are attempted about every six hours. Sources may log ordinary network requests. The web version is also subject to CORS.

3. Optional Chrome account sync

Sync requires consent covering web shortcuts, groups, information-card configuration and prompt text, tasks, and appearance / search preferences. The extension writes compressed settings to Chrome storage.sync; Chrome transfers them through your signed-in browser account when browser sync is enabled. Other devices need the same account and extension ID. No separate GentleDesk login or Google Drive authorization is used.

Local desktop files and paths, directory permissions, desktop wallpaper and layout, calendars, subscriptions, tokens, results, launch counts and tab records are excluded. Restored cards need fresh authorization. Existing local content and conflicts require a choice instead of silent replacement; a local pre-restore recovery copy is retained. A successful write is not proof that Chrome has delivered it to another device. Pausing sync or resetting this device does not delete the already synced copy in your Google / Chrome account.

4. Permissions

  • storage: local settings, optional Chrome account sync and temporary session data.
  • alarms: scheduled refresh of authorized cards and calendars, local connection checks, optional tab sleep checks and sync scheduling while Chrome runs.
  • Optional tabs: requested when you enable tab management, for the visible functions described above.
  • Optional nativeMessaging: requested for the separately installed desktop / search / system-calendar companion. The companion accepts only its registered extension ID.
  • Optional HTTPS origins: the manifest permits requesting an unknown user-chosen HTTPS service; actual access is requested for exact origins when you connect a card, calendar or macro source. There is no required all-sites host permission.

The supplied manifest does not request identity, history, cookies, website content injection, browser management or screen-recording permission. A separately configured Google OAuth build would additionally request identity for calendar authorization. All executable UI and extension code is bundled; API responses are treated as data, not remote executable code.

5. Control, export and deletion

Desktop JSON export includes web shortcuts, tasks, preferences and API configuration, possibly including your endpoint URLs and prompt text. Keep your export secure. Tokens, results, launch counts, local file / app entries and calendar records are excluded. Restoring a backup does not automatically authorize online cards.

You can edit or delete tasks and cards, disable launch ranking or tab management, disconnect calendars or the desktop, revoke permissions, or use Clear and reset in Settings. Disconnecting the desktop removes extension-side local items and attempts to clear companion records. If the companion is unavailable, use its separate uninstaller to remove its configuration. Original files and calendars are preserved.

Uninstalling the extension removes its local extension storage; the optional companion must be uninstalled separately. Web users can clear site storage in browser settings. Synced Chrome account copies are governed by Chrome's sync controls. GentleDesk has no developer-operated user-data account to delete remotely. Hosting providers for independently deployed web versions may retain ordinary access logs under their own policies; their operator must provide the applicable hosting disclosures.

6. Limited use, families and contact

Data is used only for disclosed, visible desktop functions, not advertising, sale, creditworthiness or unrelated profiling. If Google API access is enabled in a configured build, its use and transfer follow the Google API Services User Data Policy, including Limited Use. Calendar data is used only for visible calendars and explicitly confirmed writes, not ads or training general AI models. Remove Google authorization at Google account connections when applicable.

Simple mode and learning templates simplify navigation; they are not parental controls, age verification or content filtering. We do not actively collect children's identity information through the product.
