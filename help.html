GENTLEDESK

让常用的事，更容易一点。

GentleDesk 将新标签页变成你的个人桌面。默认离线可用，无需账号。

开始使用

  1. 点击“添加入口”，填写名称和完整网址。点击图标会在新标签页打开网站。
  2. 拖动图标调整顺序；“整理桌面”中可编辑、移除或用按钮调整顺序。分组通过左侧导航切换。点击“新建分组”旁的“− 移除分组”，勾选一个或多个分组后点击“移除所选”。网站入口保留在全部入口；最后一个分组也可移除。
  3. 在“桌面模板”中选择轻松上网、学习时光或专注工作。模板新增分组，不覆盖原有内容。
  4. 设置中可开启大字大图标的简易模式；关闭后恢复信息板。常用排序可选开启，仅记录本桌面点击次数。

搜索框先搜索所有分组的桌面入口。启用本地搜索后，还会显示授权文件夹中的文件、子文件夹和已安装应用入口的实时建议，不接管浏览器默认搜索。使用 ↑ ↓ 选择、Enter 打开、Esc 收起。按 / 可聚焦搜索。支持键盘 Tab 导航、Esc 关闭弹窗、减少动态效果偏好以及深浅主题。

连接电脑桌面

此功能可选。没有安装本机辅助程序时，网页入口和信息卡片仍可正常使用。首次连接会读取你选择的文件夹第一层项目，最多 250 个。导入名称、类型和图标，此后独立保存，不自动跟随系统桌面变化；需要时点击“导入桌面”补充新项目；点击时交给系统默认应用打开。

仅导入快捷入口，不复制文档内容或精确图标坐标。应用快捷方式与替身由操作系统处理。Windows 的公共桌面可单独选为同步目录；可通过分类框中的空白“添加 / 管理”图标添加任意位置的本地项目；本机登记合计最多 500 个。

只需三步

  1. 在主页点击“连接电脑桌面”，系统会自动选择 macOS 或 Windows。点击“下载安装包”。
  2. 解压，双击 Install GentleDesk.command（macOS）或 Install GentleDesk.cmd（Windows）。扩展 ID 已自动填好。
  3. 返回主页，同意本地资料使用范围，点击“连接我的桌面”并选择桌面文件夹。

无需管理员权限。系统可能显示安全确认；受组织策略管理的电脑请联系管理员。macOS 当前直接下载版仍为临时签名，正式发行需要 Developer ID 签名及公证；不要关闭系统安全保护。

Homebrew（macOS）

已安装 Homebrew 的用户，在主页展开“其他安装方式与帮助”，点击“复制命令”，粘贴到终端即可安装并绑定当前扩展 ID。命令格式：

brew install haisheng/gentledesk/gentledesk && gentledesk setup 扩展ID

这使用 GentleDesk 自己维护的公开 tap，不代表已被 Homebrew 官方主仓库收录。首次使用该 tap 可能需要 Homebrew 的信任确认。已 tap 的用户也可使用 brew gentledesk 扩展ID。

更新与卸载

更新助手后需重新运行 gentledesk setup 扩展ID，或从扩展下载新版个性化安装包双击安装。Homebrew 版通过 gentledesk uninstall 撤销当前用户的本机连接。其他方式可运行安装包中的 resources/uninstall.sh 或 resources/uninstall.ps1。卸载不删除原桌面文件。

辅助程序安装记录与目录授权存于本机。断开连接会清除入口并尝试清除目录记录。辅助程序文件及注册信息通过对应卸载脚本删除。商店分配的扩展 ID 与开发加载 ID 可能不同，正式安装时需使用正式 ID 重新注册。

“电脑桌面”中可拖动分类框标题移动，拖动右下角拉伸，使用标题按钮收起、重命名或移除。入口可拖动到其他框，外观按钮设置背景、图标大小和画布高度（480—4000px，尺寸固定，超出部分在画布内滚动查看），也可拖动画布底边改变高度；默认 900px，分类框拖动和拉伸按实际像素保存，不吸附网格、不按内容扩张，可重叠、可超出画布边界。移除入口不会删除原文件。每个分类框可独立开启文件夹搜索。开启后，文件夹图标下的“搜索”限定该文件夹及子目录，顶部只显示范围内的文件名结果，桌面图标不参与过滤；清除范围后恢复桌面图标搜索。应用和文件直接打开。入口的移动和移除也可在本框管理弹窗中完成。顶部“本机保存”前显示系统本地日期、星期和每秒更新的时间。

新标签页与 Chrome 底栏

首次安装会打开欢迎页，点击“新标签页与底栏设置指南”；也可从桌面设置顶部打开。安装并启用后会接管普通窗口的新标签页，Chrome 提示时选择“保留”。若新标签页失效，打开扩展设置，确认 GentleDesk 启用，并自行处理其他新标签页扩展冲突。无痕窗口不支持替换新标签页。

Chrome 自带底栏需手动关闭一次：在底栏空白处右键，选择“隐藏新标签页上的页脚”，或在“自定义 Chrome”中关闭“在新标签页上显示页脚”。只隐藏页脚，不要关闭 GentleDesk。本扩展无法通过公开接口预设此开关或检测状态，因此不会显示虚假的“已关闭”状态。

本地文件与应用搜索

安装 1.4.1 本机辅助程序后，点击“连接电脑桌面”中的“选择搜索文件夹”，或输入搜索词后点击建议列表下方的启用按钮。搜索授权与桌面导入分开，不会因为导入桌面而扫描全盘。macOS 可一次选择最多 5 个目录，Windows 每次选择一个目录；重新选择会替换旧范围。macOS 应用来自系统应用目录及用户 Applications，Windows 应用来自当前用户和公共开始菜单；未登记的便携应用可通过选择其所在目录搜索。

仅读取名称与位置，递归搜索子目录，跳过隐藏项目和符号链接／Windows 联接点。每次最多检查 12000 个项目、约 1.5 秒并返回最多 30 条，因此大目录可能只有部分结果；建议选择具体工作目录。系统文件 I/O 阻塞时响应可能更慢。结果过期后需重新搜索。关闭本地搜索会清除目录授权记录；原文件不受影响。手机网页不支持电脑文件和应用搜索。

苹果日历、iCloud 与提醒事项

仅支持 Mac 上的 Chrome 扩展，需要 1.5.1 本机助手。先在 Mac 的系统“日历”和“提醒事项”中登录并开启要使用的 iCloud 账户，再从插件顶部日历按钮或“全部入口”的信息板进入“连接日历”。在苹果区域确认系统权限说明，分别点击“授权苹果日历”和“授权提醒事项”，由你在 macOS 弹窗中确认；随后选择需要显示的日历和提醒列表并保存连接。系统授权是数据库级读写权限，GentleDesk 只展示和管理所选范围。

选择 iCloud 来源才能与同一账户且开启相应 iCloud 功能的 iPhone 同步；标为“仅本机”的日历不会同步到手机，只读日历不能写入。新增事件可在“保存到”选择苹果日历，修改和删除外部事件会写回所选日历，重复事件仅操作本次。提醒事项区域支持新增、修改、完成、删除、搜索与显示已完成事项；包含位置提醒的事项请在苹果 App 中编辑。插件约每分钟读取一次所选系统数据，iCloud 的实际传输和手机通知由苹果系统及设备设置决定，不能保证即时同步。

无需公开日历链接、无需输入 Apple 密码。关闭浏览器后，已经写入苹果系统的日程提醒仍由系统处理。断开只清除插件连接与缓存，不删除原日程；系统权限需到 macOS“隐私与安全性”中撤销。当前实现不邀请他人或发送邀请邮件，家庭共享成员与各自通知仍在苹果 App 内管理。

四种日历连接方式

连接弹窗分为苹果、Google、Windows、通用四个标签。苹果标签先授权，再勾选日历／列表；没有选择会显示提示，连接进度与错误固定在顶部。Google 标签默认提供私密 ICS 订阅，不公开日历；OAuth 直连需发布者配置客户端。Windows 标签支持经典 Outlook 或本地 ICS 文件持续只读同步，需要 Windows 1.5.1 助手；新版 Outlook 请使用通用 HTTPS ICS 或导出文件。通用标签保留 ICS 订阅、一次性导入和本地事件导出。

日历与当天提醒

右侧信息板提供月历和所选日期的事件；顶部日历按钮可在简易模式或手机上打开日历。点击加号新增本地事件，可编辑、删除、选择全天或时间段，以及提醒时间。全天事件的结束日期按界面所选最后一天计算，导出 ICS 时使用标准的排他结束日期。当天启用提醒的事件显示在搜索框下方滚动栏，可暂停、悬停或聚焦停止轮换，点击查看详情。到达提醒时间时，桌面打开且可见的页面会显示一次提示，多标签页通过会话记录避免重复。关闭浏览器后不由本插件弹窗。

在日历右上角的连接按钮中可以导入 .ics 文件，或订阅 Google、Apple、Outlook 等提供的 HTTPS iCalendar／ICS 地址。不是所有服务都允许直接使用网页链接：须从原服务的日历设置获取专用订阅地址。订阅与导入只读；修改原事件请回原日历。Google 私密订阅地址等同访问凭证，不要分享给他人，泄露后请在 Google 日历设置中重置。

私密地址仅保留于当前 Chrome 会话；网页版仅保留于当前页面内存，关闭后需重新连接。已缓存事件可以离线查看。连接管理中的“重新连接”可以更新现有 ICS 日历，不重复占用数量。Chrome 运行时约每 15 分钟刷新，页面打开时也会检查过期缓存；同步失败会保留缓存并显示提示。每个日历最多 1 MB 输入／2000 个展开事件，最多 5 个外部日历；本地最多 500 个事件，总日历缓存不超过 4 MB。订阅与导入覆盖上个月至未来一年，支持按天、周、月、年重复、排除日期、改期及随文件提供的时区；未知时区或更高频重复会明确提示未显示。

Google OAuth 直连代码已提供，但默认构建未配置正式客户端，入口会提示缺少配置；Google 标签页可直接连接私密 ICS 订阅。发布者完成 OAuth 登记和验收后，用户可直接通过 Google 窗口授权读取主日历，并在新增事件时确认写入。无需在 GentleDesk 输入 Google 密码。通用 ICS 不能写回原服务，本地日历可独立导出 ICS。桌面 JSON 备份不包含日历数据。

接口与 AI 信息卡片

点击信息板右上角的加号。所有接口必须使用 HTTPS，按需授予确切域名权限。令牌仅用于 Bearer 鉴权，不会长期保存，不允许放在网址中。接口结果最大 1 MB，展示最多 100 行 / 条和 6 列，请求超时 18 秒，不跟随重定向。

表格

GET https://your-service.example/status
Content-Type: application/json

[
  {"项目":"网站改版", "状态":"进行中"},
  {"项目":"用户访谈", "状态":"已完成"}
]

如果接口返回 {"data":{"items":[...]}}，字段路径填写 data.items。表格字段可留空自动读取，或填写 项目,状态。

消息

[{"text":"订单已完成"}, {"text":"今天有一场会议"}]

选择“滚动消息”，消息字段填 text。超过三条时轮换显示，可通过暂停按钮、悬停或键盘聚焦停止滚动；系统偏好减少动态效果时默认暂停。

AI 任务

POST https://your-service.example/agent
Content-Type: application/json
Authorization: Bearer YOUR_SESSION_TOKEN

{"prompt":"汇总今天的项目进度"}

响应：{"text":"今天有两个项目需要跟进…"}

请连接自己的智能体服务或协议转换网关。当前不是直接填任意聊天网站网址即可调用其 AI；服务必须提供上述接口。AI 输出以纯文本展示，不执行返回的脚本或 HTML。默认仅手动执行；设置定时刷新后会重复发送任务，第三方可能收费。

自动外观与语言

在“桌面设置”的外观中选择“按时间自动切换”，根据电脑本地时间工作。默认 06:00 浅色、18:00 深色，可以自定义两个不同的时间。电脑休眠恢复、切回标签页时会重新检查。保留旧用户手动外观；新配置默认自动模式。顶部主题按钮会切换到手动模式，自动模式可在设置中重新启用。

界面语言可选择简体中文、繁体中文、英文、西班牙语、法语、阿拉伯语，保存后即时生效并同步到其他打开的桌面标签页。阿拉伯语使用从右向左布局。菜单、弹窗、系统提示及示例信息会翻译，你自定义的名称和接口返回内容保持原文。时间与语言设置包含在备份中；这些设置只存于本机，不发送到外部服务。此独立技术帮助与完整隐私说明目前以中文提供。

手机 / 网页版

标准版手机 Chrome 不安装桌面扩展。发布者可以提供 HTTPS 网页版，使用相同的网页入口、模板和信息卡片。Android 可通过浏览器“添加到主屏幕 / 安装应用”；iPhone / iPad 可在 Safari 分享菜单选择“添加到主屏幕”。

网页版不能启动电脑上的本地应用。接口须允许网页来源的 CORS 请求；令牌和卡片结果仅在当前页面内存中保留。只有页面打开且可见时检查定时刷新，不承诺关闭页面后的后台任务。桌面与手机不自动同步账号，可通过 JSON 备份手动迁移网页配置。

常见问题

  • 打开 Chrome 后没有显示桌面：新标签页会显示本扩展。启动时若恢复上次会话，可在 Chrome 设置中自行选择“启动时打开新标签页”。本扩展不会强制改动启动设置。
  • 未能连接本机助手：核对是否安装对应系统版本、是否使用当前扩展 ID 注册，或是否被组织策略阻止。
  • 卡片提示令牌失效：会话令牌不会长期保存，重新编辑卡片并输入即可。
  • 接口失败：检查 HTTPS、证书、JSON 格式、字段路径、授权与重定向；网页版还需检查 CORS。
  • 删除本地入口：只从本桌面隐藏，不删除原文件。重新选择桌面可恢复隐藏入口。
  • 简易模式看不到信息板：简易模式优先突出入口，关闭简易模式即可显示信息板。
  • 孩子使用：学习模板提供网站入口，不提供内容过滤或家长控制，需由监护人选择适合的网站。

分类框搜索与项目看板

电脑桌面每个分类框的名称后都有搜索框，默认只筛选本框图标。允许文件夹搜索的分类框中，点击文件夹下方的搜索可切换为目录内文件搜索，清除范围后恢复图标筛选。新建分类框显示在当前可见区域，并位于最上层。分类框标题旁的“层级”可上移一层、下移一层、置顶或置底；聚焦标题后按 Alt + ↑ / ↓ 调整一层，加 Shift 直接置顶或置底。分类框使用半透明背景，层级与排版保存在本机。分类框与画布尺寸仍由用户手动控制。

全部入口下方的项目看板分为 Backlog、Planned、Processing、Finished。可创建任务、设置起止日期和说明，通过状态菜单或拖动标题切换列，使用进度滑块更新完成百分比。Finished 自动为 100%，100% 进度自动完成；重新移回其他状态时重置为 0%。任务包含在导出备份中。页面搜索左侧可切换必应、Google、百度，默认必应；直接按回车搜索网页，方向键选择建议后回车打开对应入口。

标签页休眠

在桌面设置的“可选功能”中打开标签页管理，按需授权后可查看、保护、休眠和唤醒页面。自动休眠默认关闭，需分别开启总开关和网站规则，闲置时长可选 15、30、60、120 分钟。活动、固定、播放声音、最近播放声音、协作编辑和通信页面受保护。休眠不关闭标签，再次打开会重新加载，请先保存内容。没有声称可检测全部未保存内容，也不显示虚构的内存节省数字。

全部入口的内容标签

全部入口包含三个固定标签：全部入口、日历日程、任务管理。点击后方的 ＋ 新增信息标签，填写原有信息接口配置即可。每个信息标签可切换卡片／表格，选择全部字段或某一字段搜索内容；按字段搜索匹配完整搜索文字，全部字段支持多个关键词。删除信息卡片也会移除对应标签，固定标签始终保留。

Chrome 账号同步

打开桌面设置的 Google Chrome 账号同步，勾选数据范围后启用。需在 Chrome 本身开启同步，并在其他设备使用相同 Google 账号与相同扩展 ID。无需本扩展另行登录，也不需要 Google Drive OAuth。新设备可自动恢复网页入口、信息标签、任务和偏好；本地桌面和授权不跨设备，接口需要重新授权。已有内容时选择恢复云端或保留本机；有冲突时不会静默覆盖。Chrome 存储配额约 100 KB，扩展压缩分片，超额显示错误并保留本机。可暂停当前设备或恢复同步前版本。提交成功只表示已写入 Chrome 存储，不代表跨设备传输已经完成。

任务快捷操作与甘特图

“我的任务表”上方可按任务名实时筛选，支持多个关键词和英文大小写；显示匹配数量，Enter 定位首个结果，Esc 或清除搜索恢复全部任务，泳道与甘特图共用筛选条件。任务卡片采用紧凑排版，状态、等级和进度合为一行；标题和说明超长时省略，悬停可查看完整内容，点击标题可编辑。

任务管理默认泳道视图，点击泳道标题的 ＋ 或新增任务，只填名称即可保存。更多属性是选填项，正文可滚动，取消和保存固定在底部。卡片或甘特图左侧可直接调整状态及 P0 紧急、P1 高、P2 普通、P3 低等级；点击标题或时间条编辑，× 删除需确认。甘特图没有日期的任务显示未排期，点击可设置日期，不会自动编造日期。视图和等级会保留，并包含在备份与可选同步中。

Chrome 自带的 GentleDesk · A simpler desktop 底栏独立于扩展页面：在其空白处右键选择 Hide footer on New Tab page，或在 Customize Chrome 的 Show footer on New Tab page 中关闭。不要禁用扩展本身；如果新标签页恢复默认 Chrome 页面，可在 chrome://extensions 中重新启用 GentleDesk，并在出现控制提示时选择保留扩展的新标签页设置。

空间管理与宏观模板

我的空间列表支持独立滚动，底部连接、模板与设置保持可见。除全部入口和电脑桌面外，可通过“− 移除分组”的 checkbox 列表单选或批量移除；手机端可点击顶部的 − 打开相同列表。分组内的网站入口保留在全部入口，最后一个分组也可移除。宏观经济观察移除后，可从桌面模板重新添加。

精确添加本地项目

点击分类框中的“添加 / 管理”，再选择“添加文件夹”“添加文件”或“添加应用”。需要 1.6.3 或更新版本本机助手。系统选择窗口打开时，网页管理弹窗会暂时收起；双击文件夹进入子目录，选中目标后确认。添加文件夹时保存所选文件夹本身，不自动加入全部子文件。文件支持按住 ⌘（Windows 为 Ctrl）或 Shift 多选，选择后回到同一管理窗口，可继续添加。取消不会新增项目；错误会显示在窗口内。所有添加项归入当前分类框。

甘特图视图右上角的“导出 Excel”会下载 .xlsx 甘特图，包含任务名称、状态、等级、起止日期、完成百分比、备注和按日期着色的排期。搜索时仅导出匹配任务；未排期任务保留且日期为空，单日期任务显示为单日。跨度较长时自动按周、月或年显示，绿色表示对应排期已完成的部分。表头与序号、名称列冻结，可在 Excel 中筛选任务。文件是导出时的排期快照，修改 Excel 不会更新插件。

日程列表和苹果提醒事项每项右侧均提供“删除”，也可在详情弹窗底部删除。确认后会删除所选苹果日历中的本次事件或提醒事项，并由 iCloud 等账户同步到其他设备；Google OAuth 直连事件确认授权后也可删除。只读 ICS、Windows 和只读苹果日历须在原应用删除。删除失败会保留当前项目并显示错误。事件详情中的“颜色标注”提供六种颜色及默认色，已有事件可单独点击“保存颜色标注”，无需写入原日历。标注仅保存在本机，外部同步和页面刷新后保留；月历圆点、当天日程、顶部提醒条以及苹果提醒事项显示对应颜色。新建外部事件／事项后可重新打开详情标注。
