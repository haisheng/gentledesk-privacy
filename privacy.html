GENTLEDESK · 智能桌面

隐私政策与数据说明

版本 1.6.3 · 生效日期：2026 年 10 月 28 日

GentleDesk（项目代号 DeskAssit）将新标签页变成可定制的桌面，提供快捷入口和用户自行连接的信息卡片。手机网页版提供对应的入口与信息板。本政策覆盖扩展、网页版及可选的 macOS / Windows 本机辅助程序。

默认不联网获取桌面信息，不使用广告、分析 SDK 或行为追踪，不出售用户数据。只有在你主动访问网站或授权连接接口、外部日历或宏观数据更新后，才会发生对应的网络请求。

1. 数据及其用途

数据用途与保存位置
网页入口名称、网址、分组、排序、界面设置（包括语言及本地时间主题时段）、称呼展示你的桌面。扩展保存于 Chrome 本地存储；网页版保存于当前站点本地存储，默认不进行账号云同步；主动开启 Chrome 同步后的范围见下文。
入口点击次数与最近点击时间仅在你主动启用“常用入口优先”后记录，只记录从本桌面打开入口的操作，不读取浏览历史，不上传。关闭功能即清除记录。
接口地址、字段映射、刷新频率、AI 任务文字保存于本机，用于你授权的信息卡片。AI 任务属于用户输入内容，可能包含个人信息，请按实际需要填写。
Bearer 令牌可选。扩展只保存在 Chrome 的会话内存存储中，浏览器会话结束后清除；网页版只保存在当前页面内存中，刷新或关闭页面即丢失。不写入持久存储、日志或备份。
公开宏观经济数据与更新开关随包附带公开数据快照。启用联网后，公开观测及抓取日期缓存在本机持久存储，不含账户信息。暂停更新可停止定时请求；清除本机数据会清除此缓存并暂停更新。不写入桌面备份。
接口与 AI 返回结果仅用于卡片展示。扩展保存于会话存储，网页版保存在页面内存中。删除卡片、清除数据或结束相应会话后清除。
本地项目名称、类型、图标、标识仅在连接辅助程序并选择目录或具体项目后读取，保存在本机以展示和打开入口。不会发给接口或 AI 服务。辅助程序保存所选目录和项目的路径及 macOS 授权书签；不读取文档内容，不修改或删除原文件。
本地搜索词、文件和应用的名称、位置全局搜索需单独启用并选择目录；也可搜索已主动添加的文件夹。macOS 搜索应用目录，Windows 搜索开始菜单；递归搜索所选文件夹，不读取文档正文。搜索词与结果仅用于本机建议和打开项目；扩展后台的结果列表短暂保留，最长 60 秒可打开。不写入桌面备份，不交给网络卡片、AI 或日历。
日历事件名称、时间、提醒、地点、备注及订阅缓存本地事件和外部日历的事件缓存保存在本机，供月历、日程和提醒使用。不自动交给 AI。桌面 JSON 备份不含日历，本地事件可单独导出 ICS。断开外部日历会清除该日历的本机缓存，不删除服务端事件。
私密 ICS 订阅地址、Google OAuth 令牌私密订阅地址可能包含访问凭证，完整地址仅放在扩展会话存储；网页版仅放在当前页面内存。关闭浏览器或网页后需重新连接；本机保留日历名称、服务域名及上次事件缓存。Google OAuth 由 Chrome 身份 API 管理，不要求在本插件输入 Google 密码，不将令牌写入本地配置、导出或日志。

苹果日历与提醒事项

在 macOS Chrome 扩展中可通过另行安装的 1.5.1 本机助手连接系统日历和提醒事项。只有你主动点击授权后才请求相应系统权限；系统读写授权覆盖该类数据库，插件仅缓存你随后选定的日历与列表。事件的标题、时间、地点、备注、提醒设置，以及提醒事项的名称、到期时间、备注和完成状态保存在本机，用于展示、编辑与提醒。所选日历／列表的名称和账户名称保存在本机以标明来源，不读取 Apple 账户密码，不发送给 GentleDesk、AI 或接口卡片。

写入和删除由用户在界面确认；系统账户（例如 iCloud）会按自身设置同步到其他设备并处理通知。插件不能保证即时到达手机或强制开启手机通知。苹果连接不需要公开订阅链接。断开连接清除插件缓存及助手中的选择和引用，不删除苹果日历或提醒事项；如需撤销 macOS 系统授权，请在系统设置的隐私与安全性中关闭 GentleDesk 的日历／提醒事项权限。桌面备份不包含这些数据。

Windows 本地日历

需要 Windows Chrome 扩展及 1.5.1 本机助手。你主动检测经典 Outlook 或选择本地 ICS 文件后，助手列出候选日历；只有勾选并连接的日历／文件会定时读取。插件缓存标题、时间、地点、提醒设置及日历名称，不读取 Outlook 邮件、联系人或密码，不发送给网络卡片或 AI。本地 ICS 需要读取所选文件正文以解析日程；路径仅保存在助手的用户专属配置中，扩展接收不透明引用与日程内容。连接为只读，不修改原日历，不发送邀请；断开只清除选择与缓存。新版 Outlook 不支持本 COM 连接，可使用 HTTPS ICS 或导出本地 ICS 文件。Windows 本地源约每分钟刷新；账户自身同步和系统通知仍由 Outlook 处理。

标签页管理、项目任务与网页搜索

标签页管理默认关闭，主动授权后才读取普通网页标题、网址和状态；不会读取网页正文或浏览历史。列表只在本机处理，网站规则保存在本机，活动时间和休眠计数仅存于 Chrome 会话存储，不保存完整网址或标题。自动休眠初始关闭，仅对你明确允许的网站执行。休眠通过 Chrome 卸载页面并保留标签，再次打开将重新加载，未保存内容可能丢失；无法保证识别所有后台任务，请保护重要网站。关闭管理清除规则及会话记录，并撤销可选 tabs 权限，不关闭已有标签页。

项目看板的名称、备注、日期、状态、等级和完成百分比默认保存在本机并包含在 JSON 备份中。网页搜索默认必应，可切换 Google 或百度；只有提交搜索时才向所选搜索服务发送搜索词，目录内文件搜索不会发送到这些服务。工作空间预装“工具 / Tools”网站入口，页脚提供同站友情链接；不自动访问或预加载该站点，也不记录链接点击统计。

Google Chrome 账号同步（可选）

只有主动勾选同意并点击开启后，本设备才向 chrome.storage.sync 写入网页入口名称、完整网址、分组、信息接口配置（地址、映射、提示文字、卡片／表格视图）、项目任务（名称、说明、日期、进度）和外观／语言／搜索引擎偏好。Chrome 按浏览器账号与同步设置负责向 Google 同步；本扩展不获取 Google 账户密码、登录令牌或浏览器个人资料，也不提供 Google Drive 云盘备份。如果浏览器同步关闭，数据仅存于该设备的 Chrome 同步存储区，界面的提交时间不表示 Google 已收到或其他设备已获取。

不上传电脑桌面、本机应用和文件入口、目录路径、背景图片和桌面排版、目录授权、日历事件与私密订阅、会话令牌、接口结果、入口点击记录或标签页记录。信息接口在新设备恢复后处于暂停状态，需要重新授权。网页 URL 与接口地址、任务说明可能含有你主动填写的个人内容，启用前请检查；请勿将密码或秘密写入任务或网址。Chrome 同步不是本产品的加密保险库。

首次启用时可选择保留本机上传或恢复已有云端版本。此前从未使用的新设备，在相同扩展 ID 与同一 Chrome 同步账号下可自动恢复。已有本机内容的设备不会自动覆盖，须主动选择；双方都有修改时暂停自动合并并提示选择版本。恢复前保留一份本机配置，可暂停同步后恢复。暂停仅停止当前设备的同步，现有 Chrome 云端副本仍保留；如需移除 Google 保存的数据，可在 Chrome／Google 账号的同步管理中处理。清除本机数据会暂停此设备同步，不删除云端副本。同步采用压缩分片并校验完整性，超出容量或网络分片未齐时保留本机及上一版本并显示错误，不承诺实时送达。

2. 外部服务与传输

数据卡片只向你明确配置并同意连接的 HTTPS 接口发送请求。表格和消息使用 GET；AI 卡片使用 POST，内容为你填写的任务文字。选择 Bearer 鉴权时，会在请求头附带你输入的令牌。不自动附加本地文件、其他卡片、使用记录、浏览历史或 Cookie。不跟随接口重定向。

自动刷新会重复发起相同请求；AI 服务可能按调用收费。第三方服务对请求数据的保留和使用由其自身政策决定，连接前请确认你信任该服务。访问网页快捷方式后，该网站独立处理访问数据。

没有 GentleDesk 运营的默认数据或 AI 后端。模板、图标与演示信息随程序打包，不需访问第三方图片、字体或统计服务。手机网页版的托管服务在提供网页时可能产生常规访问日志（例如 IP 地址和资源请求）；部署运营者应在自己的发布页面说明其托管服务与保留政策。

日历订阅只请求用户明确授权的 HTTPS 服务，不携带浏览器 Cookie，不跟随重定向。Chrome 运行时约每 15 分钟刷新；网页版只在页面打开时检查。Google 直连启用后，从 Google 日历 API 读取用户主日历的事件。新增 Google 事件需再次明确同意，并只发送该事件的标题、开始结束时间、地点、备注和提醒设置；不自动发送本地搜索、文件、密码或其他卡片的数据。ICS 订阅只读，不写回原服务。外部服务可记录请求及按自身政策处理数据。

本机辅助程序不包含网络请求代码，目录同步和本地搜索由本机程序完成。点击网站、打开应用、启用外部卡片和日历时，对应网站或应用可能联网，因此不能把整个产品描述为“任何情况下都不联网”。

下载个性化助手安装包时，扩展在本机将当前扩展 ID 写入随包附带的安装配置，不把 ID 上传到服务器。双击安装只为当前用户登记该精确 ID。Homebrew 安装会从 Homebrew／GitHub 下载公开的软件源码和依赖，这些服务可能保留常规下载日志；扩展 ID 只传给本机的 setup 命令，不用于下载请求。不自动安装 Homebrew，不自动运行终端或绕过系统安全确认。

宏观数据联网更新仅向纽约联储、美国财政部、TreasuryDirect、Investing.com 与 IMF 请求公开数据，不附带账户信息、Cookie 或其他卡片内容。点击启用后申请相应精确域名权限，在页面可见期间每 6 小时尝试更新；第三方服务可能保留常规请求日志，普通网页受 CORS 限制。

3. 权限

  • storage：保存桌面配置和会话数据。
  • alarms：在 Chrome 运行时按你设定的周期刷新已授权卡片和外部日历。
  • 可选 HTTPS 域名访问：仅在连接接口、外部日历或启用宏观数据更新并点击授权时申请对应域名，不默认申请访问所有网站。
  • 可选 tabs：仅在开启标签页管理时申请，用于显示标题网址、休眠唤醒及复用已有页面；不读取页面正文。
  • 可选 nativeMessaging：仅在你启用电脑桌面、本地搜索或苹果／Windows 本地日历时申请，用于与本机辅助程序通信。辅助程序只接受安装时指定的扩展 ID。
  • 可选 identity（仅配置 Google 直连的构建）：仅用于用户主动授权 Google 日历，读取主日历事件或在再次同意后新增事件。不申请 identity.email，不读取 Chrome 个人资料。

不申请浏览历史、网站内容注入、Cookie、浏览器管理、屏幕录制或任意 Shell 命令执行权限。手机网页版没有 Chrome 扩展权限；接口请求受浏览器 CORS 限制，页面关闭后不保证后台刷新。

4. 保存、导出与删除

设置中的“导出备份”会生成包含网页入口、搜索引擎偏好、项目任务与接口配置的 JSON 文件，可能包含你输入的任务文字和接口地址；请妥善保存。备份不含令牌、结果缓存、使用频率或本地文件入口。恢复备份不会自动启用接口，需重新同意和授权。

你可以删除单张卡片、关闭常用排序、断开电脑桌面，或清除所有本机数据。删除卡片将清除令牌与缓存，并在没有其他卡片或日历使用该域名时撤销对应权限。断开电脑桌面会清除扩展中的本地项目，并尝试清除辅助程序记录；如果辅助程序已不可用，可运行附带的卸载脚本清除其配置。

卸载扩展会删除扩展存储；辅助程序独立安装，需独立卸载。网页版可通过站点设置清除存储。没有开发者云端账号数据可供远程删除。

5. 儿童与家庭

简易模式和学习模板用于降低操作难度，不提供家长控制、年龄验证、内容过滤或第三方服务适龄保证。建议监护人选择适合儿童的网站；令牌和 AI 接口应由有权使用的成年人配置。我们不通过本产品主动收集儿童身份资料。

6. Limited Use 与联系

GentleDesk 对用户数据的使用仅限于本产品已披露的桌面功能，不出售数据，不用于广告、信用评估或与功能无关的用途。对通过 Google API 获取的数据，使用与转移将遵守 Google API Services User Data Policy（包括 Limited Use 要求）；Google 日历数据仅用于用户可见的日程展示和明确授权的新增事件，不用于广告或训练通用 AI 模型。当前默认构建未配置正式 Google OAuth 客户端，直连入口会提示缺少客户端配置；启用前须完成 Google 端登记、验证及实际账户验收。用户可先选择只读 ICS 订阅。

English summary

Optional Chrome account sync requires explicit consent before this device writes web shortcuts, groups, API configuration and prompt text, project tasks and appearance/search preferences to Chrome storage.sync. Chrome handles transfer through the signed-in browser account when browser sync is enabled. We do not access Google credentials or use Google Drive. Local desktop data, paths, file/app entries, wallpaper/layout, directory permissions, calendar data, private subscriptions, tokens, results, usage and tab records are excluded. New devices with the same extension ID can restore settings; APIs require fresh authorization. Conflicts require a version choice and a local pre-restore recovery copy is retained. Submission is not proof of Google delivery. Pausing or resetting stops this device while the synced copy remains in the Google/Chrome account.

Tab management is off by default. Optional tabs permission enables local title/URL listings, discarding, waking and shortcut reuse. Automatic sleep requires both global and site opt-in; discarded pages reload and unsaved work may be lost. Session records store IDs and timestamps, not full URLs or titles. Disabling clears policies and revokes tabs access. Project tasks stay local and are included in backups. Explicit web searches send the query only to the selected Bing, Google or Baidu provider. The preinstalled Tools shortcut and footer link do not trigger automatic visits or click tracking.

GentleDesk is a local-first new tab desktop. Shortcuts and preferences stay on your device. Optional usage ranking only counts launches from this desktop. Optional API widgets send requests to HTTPS endpoints you explicitly configure and authorize; AI widgets send only your written prompt. Credentials and responses are session-only (page-memory-only on the web). Desktop integration is opt-in, requires a separate native connector, and reads names, types and icons from your selected folder without uploading document contents. No advertising, analytics or data sales. You can remove widgets, revoke permissions, export a secret-free backup, or clear local data. Local search reads names and locations only within selected folders and known app directories. Public macro observations are bundled and cached locally; optional updates request public data from the New York Fed, US Treasury, TreasuryDirect, Investing.com and IMF without account information. Clearing local data removes this cache and disables updates. Calendar events and external calendar caches stay on the device. ICS subscription URLs are session-only. Authorized Google Calendar access reads primary-calendar events; creating an event sends only the fields explicitly confirmed by the user. Calendar data is never automatically sent to AI. Google OAuth is disabled in the default build until the publisher configures and verifies its OAuth client. Calendar data follows the Google API Services User Data Policy, including Limited Use. This is not a parental-control product. For product support, privacy or data questions, contact taihushuicao_lu@qq.com or use the Chrome Web Store listing's support channel.
